
### 📘 Project Overview

Designed and analyzed a relational database for employee management using **MySQL**. Implemented complex **JOINs, CTEs, stored procedures, triggers, and events** to automate HR operations and extract actionable workforce insights.

This project focuses on building and managing a **relational database** for a fictional government department, *Parks and Recreation*.

The process started by designing **normalized tables** for employee demographics, salaries, and departments, establishing relationships through primary and foreign keys.

### 🧠 Skills & Techniques
- SQL data modeling, data analysis, and automation using MySQL  
- Filtering, grouping, and aggregating employee data to explore salary trends and demographics  
- Using **JOINs** and **CTEs** to combine and summarize data efficiently  
- Applying **Window Functions** for ranking, rolling sums, and averages by gender  
- Creating **Stored Procedures** for dynamic queries  
- Writing **Triggers** to automatically update employee records upon salary insertions  
- Scheduling **Events** to automate deletions for employees over 60 years old
